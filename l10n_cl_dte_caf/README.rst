Registers Chilean folio authorizations (CAF) by company, document type
and SII environment. Protects the file and records its SHA-256 digest.

.. contents::
   :local:

Usage
=====

Assign **DTE Manager** to users who register CAF files and **DTE User**
to users who inspect authorization metadata for their allowed companies.
This technical addon registers draft authorizations. Validation of the
SII signature and folio reservation are separate follow-up features. CAF
registration alone does not authorize a DTE to be issued.
